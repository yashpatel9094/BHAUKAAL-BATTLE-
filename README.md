# BHAUKAAL

Browser battle royale (three.js). Solo (bots) + online multiplayer rooms (login, code, 4-30 players).

- Local: `node server.js` -> http://localhost:8000
- Vercel: static `public/` + `api/` functions. Env: `REDIS_URL` (ya Upstash REST vars) + `AUTH_SECRET`.
- Icons: Lucide (ISC). `node tools/build-icons.mjs` se `public/icons.js` dobara banta hai.
